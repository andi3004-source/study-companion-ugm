# Tugas R4 (riset): keamanan Tuturnusa tanpa akun
Pakai skill riset yang terpasang (brainstorming-research-ideas, creative-thinking-for-research, autoresearch) dan pencarian web. Baca `docs/orchestra/00-konteks-bersama.md`, rancangan `docs/superpowers/specs/*-refactor-design.md` dan `*-rancangan-sistem.md`, lalu PELAJARI KODE yang sekarang (`routes/web.php`, `app/Providers/AppServiceProvider.php` rate limiter, `app/Services/ConversationService.php`, `app/Livewire/Conversation/*`, `app/Livewire/PronunciationCheck.php`, `app/Http/Controllers/{BukuSakuController,VoiceCommandController}.php`, `app/Support/BukuSakuCatalog.php`, `config/session.php`, `bootstrap/app.php`, `public/sw.js` template `resources/js/sw.template.js`, `Dockerfile`, `docker-compose.yml`).

Konteks: aplikasi publik TANPA login untuk anak tunanetra. Ngobrol memanggil API AI berbayar; Ucapan menerima unggahan audio dan memanggil layanan pemeriksa ucapan; ada endpoint perintah suara; PWA dengan service worker. Data Ngobrol dihapus setelah 24 jam.

Tulis HANYA `docs/research/04-keamanan-tanpa-akun.md`:
1. Model ancaman (STRIDE singkat) khusus aplikasi publik tanpa akun: penyalahgunaan biaya AI (denial-of-wallet), bot/scraper, prompt injection ke AI dan keluaran AI yang tidak pantas untuk anak, unggahan berbahaya/berukuran besar, XSS (Livewire, Markdown), CSRF, session fixation/hijack pada sesi anonim, enumerasi ID sesi, IP palsu di balik proxy (X-Forwarded-For), cache poisoning service worker, SSRF/akses file, kebocoran kunci API, header keamanan, privasi data anak (UU PDP).
2. Untuk SETIAP ancaman: apakah kode sekarang sudah menanganinya (sebut file:baris sebagai bukti), celah yang tersisa, dan rekomendasi konkret dengan prioritas (P0/P1/P2). Jangan mengarang: kalau belum dicek, tulis "belum diverifikasi".
3. Kontrol yang disarankan untuk Laravel 12 + Livewire 3 + FrankenPHP/Caddy: rate limit berlapis (per IP, per sesi, global harian + batas anggaran biaya AI), CAPTCHA yang AKSESIBEL untuk tunanetra (bandingkan Cloudflare Turnstile mode invisible, hCaptcha aksesibilitas, proof-of-work; hindari CAPTCHA visual), moderasi keluaran AI untuk anak, Content-Security-Policy yang cocok dengan Alpine/Livewire, header (HSTS, X-Content-Type-Options, Referrer-Policy, Permissions-Policy untuk mikrofon), batas ukuran unggahan di Caddy dan PHP, logging tanpa data pribadi, rotasi kunci.
4. Daftar periksa yang bisa diuji (untuk E2E/CI).
Setiap klaim teknis disertai URL sumber (OWASP, Laravel/Livewire docs, MDN, Cloudflare/hCaptcha docs, W3C tentang CAPTCHA aksesibel). Akhiri dengan "Rekomendasi untuk Tuturnusa" bernomor, urut dari P0. Jangan ubah file lain. Jangan commit.
