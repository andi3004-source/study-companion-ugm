# Tugas R2 (Antigravity): riset design system untuk tunanetra dan low vision
Baca `docs/orchestra/00-konteks-bersama.md` dan rancangan di `docs/superpowers/specs/`. Lihat juga `tailwind.config.js` dan `resources/css/` untuk token warna dan font yang ada sekarang.

Riset di web, lalu tulis HANYA file `docs/research/02-design-system.md`. Isinya:
1. Prinsip design system untuk pengguna buta total (struktur semantik, landmark, heading, urutan fokus, nama aksesibel kartu/tautan) dan low vision (kontras WCAG 2.2 AA/AAA, ukuran teks minimal, reflow 320px, zoom 200–400%, mode kontras tinggi / `forced-colors`, `prefers-reduced-motion`, indikator fokus WCAG 2.4.11/2.4.13, target sentuh 2.5.8). Tiap poin dengan URL.
2. Contoh design system nyata yang kuat aksesibilitasnya (GOV.UK Design System, USWDS, dan lain-lain): apa yang layak ditiru untuk 3 kartu besar dan halaman bacaan.
3. Kebutuhan khusus anak: bahasa sederhana, panjang kalimat, dan ikon yang tidak wajib dimengerti.
4. Usulan token konkret untuk Tuturnusa: palet (cek rasio kontras tiap pasangan, tulis angkanya), skala tipografi (rem), spasi, radius, gaya fokus, ukuran kartu, layout beranda desktop dan mobile. Pertahankan identitas warna navy dan oranye kalau lolos kontras.
5. Daftar periksa (checklist) yang bisa dipakai QA nanti.
Akhiri dengan "Rekomendasi untuk Tuturnusa" berupa daftar bernomor.
