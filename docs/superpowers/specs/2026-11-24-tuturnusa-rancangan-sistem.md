# Rancangan sistem Tuturnusa setelah refactor tiga fitur

Status: rancangan implementasi, **belum diterapkan**. Sumber keputusan produk: [rancangan yang disetujui](2026-11-24-tuturnusa-tunanetra-refactor-design.md). Audit kode dilakukan pada 24 November 2026. Penanda **[usulan Codex]** berarti keputusan teknis tambahan di dokumen ini, bukan keputusan pada rancangan awal. Tidak ada perubahan kode atau rencana tugas dalam dokumen ini.

## 1. Peta sistem tujuan

### Rute aplikasi

Semua rute web memakai kelompok middleware Laravel `web` (session, cookie, CSRF); tidak memakai `auth`, `verified`, `guest`, atau `onboarded`. `POST /voice/command` juga melewati CSRF. URL MP3 adalah aset statis server web, bukan rute Laravel. Rute internal Livewire (`/livewire/update`, upload sementara) tetap disediakan oleh paket Livewire dan mengikuti middleware paket; jangan ditafsirkan sebagai rute produk.

Rute halaman penuh memakai `<a href>` biasa, tanpa `wire:navigate`, supaya perubahan `<title>` dan konteks fokus mengikuti navigasi dokumen bawaan browser ([Livewire Navigate](https://livewire.laravel.com/docs/3.x/navigate), [WCAG 2.4.2](https://www.w3.org/WAI/WCAG22/Understanding/page-titled.html)).

## 2. Alur data dan batas kepercayaan

| Fitur | Alur | Batas kepercayaan dan batas laju |
|---|---|---|
| Ngobrol tanpa akun | Pilih bahasa/skenario → `Picker` memvalidasi key lewat `ConversationService::scenario()` → buat `ConversationSession.user_id=null`, simpan ID dalam session Laravel `ngobrol.sesi` → navigasi `Chat` → teks ketik/STT masuk `sendMessage()` → validasi 1–500 karakter → `AiClient` → simpan turn dan token → opsional akhiri sesi, antrekan `AnalyzeSessionJob`, polling hasil. | Semua properti/argumen Livewire adalah input tidak tepercaya. Cek ID terhadap session server pada `mount`, setiap computed yang membaca sesi, `sendMessage`, `finishSession`, dan `pollAnalysis`; 404 bila tak berhak. Teks AI dianggap tidak tepercaya, tampil via escaping Blade; jangan render sebagai HTML. Limit per IP: `RateLimiter` 1 menit dan 24 jam pada **aksi kirim** sebelum API; pembuka sesi acak dan feedback akhir juga memakai AI, maka batasi **aksi mulai/akhir** per IP agar biaya tak dapat dilewati **[usulan Codex]**. Hanya hitung pesan yang berhasil; pesan galat dibacakan status. [Laravel rate limiting](https://laravel.com/docs/12.x/rate-limiting), [Laravel authorization](https://laravel.com/docs/12.x/authorization). |
| Ucapan | Pencarian kata → `KamusSearchService` query terbatas → pilih baris → browser merekam audio + opsional transkrip STT → upload sementara Livewire → `PronunciationChecker` ML atau fallback STT → hasil teks. | `query`, bahasa, identitas kata, transkrip dan berkas audio tidak tepercaya. Validasi bahasa, ukuran/MIME/durasi audio dan verifikasi ulang pilihan terhadap data kamus sebelum mengecek **[usulan Codex]**; properti `selectedWord` publik saat ini dapat dimodifikasi. Rate limit per IP pada aksi cek dan batas ukuran upload, bukan hanya endpoint suara **[usulan Codex]**. Jelaskan bahwa rekaman dikirim ke server pemeriksa, dan STT browser dapat memakai penyedia browser. Berkas sementara dibersihkan sesuai retensi Livewire. |
| Buku Saku | Developer ekstrak PDF → review Markdown → `tts.py` menghasilkan MP3 dan manifest durasi → deploy file → request GET membaca slug yang ada di katalog → front matter + Markdown → HTML aman → MP3 statis dimuat hanya setelah pengguna menekan kontrol. | PDF/Markdown adalah konten repo yang harus direview; front matter dan tautan Markdown tetap divalidasi, HTML mentah dibuang, unsafe links ditolak. Jangan membentuk path langsung dari slug request; enumerasi file terdaftar dahulu. `../`, encoded traversal, bab tak dikenal → 404. Tidak ada rate limit fitur khusus untuk GET statis. Durasi manifest dibandingkan dengan MP3 saat build **[usulan Codex]**. [Laravel Markdown](https://laravel.com/docs/12.x/strings#method-str-markdown), [OWASP XSS](https://cheatsheetseries.owasp.org/cheatsheets/Cross_Site_Scripting_Prevention_Cheat_Sheet.html). |
| Mode suara | Pengguna tekan tombol → hentikan audio aplikasi lain → izin mikrofon dan pemberitahuan privasi → satu ujaran `SpeechRecognition.continuous=false` → transkrip/alternatif ke `/voice/command` → parser mengembalikan `type,target,index` → adapter menavigasi atau menekan kontrol yang sudah ada. | Transkrip server dibatasi 200 karakter dan jumlah alternatif; hasil parser hanya route allowlist, bukan URL dari pengguna. `throttle:voice-command` per IP tetap. Tidak ada hotkey huruf tunggal, aktivasi ulang mikrofon otomatis, atau penyimpanan transkrip. Setelah satu perintah status diumumkan dalam `role=status`, mikrofon tertutup; aksi berikutnya perlu tekan tombol lagi. [MDN Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API/Using_the_Web_Speech_API), [WCAG 2.1.4](https://www.w3.org/WAI/WCAG22/Understanding/character-key-shortcuts.html). |

**[usulan Codex]** Karena job analisis menerima ID numerik, saat `handle()` berjalan ia harus mengambil sesi yang masih ada dan tidak menulis hasil ke sesi yang sudah dipruning. Akses hasil tetap ditentukan oleh pemeriksaan session browser pada `Chat`, bukan oleh ID job. Retensi DB berdasarkan `started_at` lebih dari 24 jam, prune per jam; karena jadwal, data dapat bertahan mendekati 25 jam. Log, backup, antrean, serta penyedia AI/STT memerlukan kebijakan terpisah. Pemberitahuan privasi harus mengatakan hal ini dengan jujur. Keputusan persetujuan wali perlu tinjauan hukum sebelum rilis untuk anak ([UU PDP, Pasal 25–28](https://peraturan.bpk.go.id/Download/224884/UU%20Nomor%2027%20Tahun%202022.pdf)).

## 4. Kontrak antarmuka dan berkas

### Buku Saku

Satu file per pengantar/bab/gerakan: `resources/buku-saku/<slug-buku>/<NN>-<slug-bab>.md`; `NN` dua digit `00` untuk pengantar, `01`–`15` atau `01`–`12` untuk isi, `99` untuk referensi jika ada. Front matter wajib berupa tiga key sederhana dan **tanpa YAML kompleks** **[usulan Codex]**:

```md
---
judul: Menyikat gigi mandiri
bagian: Perawatan diri
urutan: 4
---

## Alat dan bahan

...

## Langkah-langkah

1. ...
2. ...

## Patokan selesai

...
```

`judul` dan `bagian` adalah string satu baris nonkosong, `urutan` integer sama dengan prefiks `NN`; tidak ada `#` judul di body karena halaman menyediakan satu `<h1>` dari `judul` **[usulan Codex]**. Bagian untuk daftar isi berasal dari metadata, urutan dari `urutan` lalu nama file; duplikasi nomor/slug, field tak dikenal, Markdown kosong, dan MP3/manifest yang hilang gagal pada pemeriksaan build **[usulan Codex]**. Heading body mulai `<h2>`; `###` hanya subbagian. PDF “Page x of y” dibuang, heading patah halaman disambung, dan hasil 15 bab + 12 gerakan diperiksa manual. Tabel prinsip/persiapan diubah ke heading dan paragraf.

MP3: `public/audio/buku-saku/<slug-buku>/<NN>.mp3`; nomor cocok dengan Markdown. `manifest.json` berisi object keyed by `"<slug-buku>/<NN>"`, nilai `{ "durasi_detik": 252, "berkas": "<slug-buku>/<NN>.mp3" }` **[usulan Codex: bentuk manifest]**. Durasi integer positif dihasilkan setelah MP3 selesai, diverifikasi dari file audio, dan dipakai sebagai teks sebelum `<audio>`; waktu tidak diambil dari `preload`. Jika Markdown berubah, regenerasi MP3 dan manifest pada commit yang sama; skip TTS hanya bila MP3 lebih baru **dan** metadata durasi valid **[usulan Codex]**. Kunci manifest tidak berasal dari request bebas. `tts.py` memakai `edge-tts` `id-ID-GadisNeural`, `rate=-10%`, menyuarakan heading dan “Langkah satu, …”; review dengar 2–3 bab per buku sebelum semua audio disahkan. `requirements.txt` memuat `edge-tts`. Risiko API tidak resmi dan opsi migrasi ke Gemini TTS dicatat dalam komentar script. [edge-tts](https://github.com/rany2/edge-tts), [MDN audio](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/audio).

### API Ngobrol dan session

Kontrak publik `ConversationService` setelah refactor (tipe kembali lainnya tetap seperti sekarang):

```php
public function startSession(string $lang, string $scenarioKey): ConversationSession;
public function startRandomSession(string $lang, ?string $topicOverride = null): ConversationSession;
public function scenario(string $lang, string $scenarioKey): array;
public function scenarios(string $lang): array;
public function scenarioDisplay(ConversationSession $session): array;
public function sendMessage(ConversationSession $session, string $content, string $inputMode = 'text'): ConversationTurn;
public function endSession(ConversationSession $session): array;
public static function dailyMessageLimit(): int;
```

`startSessionForTopic()` saat ini hanya dipanggil dashboard lama; **[usulan Codex]** hapus method itu beserta `matchingScenarioKey()` setelah grep pemakai akhir. `messagesSentToday(User)`/`remainingMessagesToday(User)` dihapus; sisa kuota ditentukan limiter per IP, dengan hitungan ditampilkan tanpa user. `sendMessage` tetap menghapus turn pengguna jika AI gagal; pembuka acak tetap menghapus sesi kosong saat AI gagal. Semua factory sesi yang sukses menambahkan ID ke `session()->push('ngobrol.sesi', $id)` hanya setelah pembuatan/pembuka sukses **[usulan Codex]**. Kunci `ngobrol.sesi` menyimpan array ID integer, tidak dipakai sebagai URL atau data client; normalisasi `intval`/strict comparison saat cek. `SESSION_EXPIRE_ON_CLOSE=true` memutus akses saat cookie browser ditutup; pruning DB terpisah. Kunci internal mode suara yang sudah ada tidak boleh menjadi otorisasi sesi. [Laravel session](https://laravel.com/docs/12.x/session).

## 5. Halaman dan aksesibilitas

Semua halaman: `<html lang="id">`, `<title>` unik, skip link pertama ke `<main id="konten" tabindex="-1">`, landmark `<header>`, `<main>`, `<footer>`; header DOM menempatkan tombol Mode suara **sebelum** tautan logo agar urutan Tab sesuai rancangan verifikasi, meskipun logo tampil kiri **[usulan Codex: urutan DOM]**. Tidak ada sidebar/bottom bar. Tautan “← Beranda” menjadi kontrol pertama di `<main>` setiap fitur. Fokus keyboard tetap pada elemen yang memicu update kecil; setelah navigasi penuh, browser mulai halaman baru dan pengguna dapat menggunakan skip link/heading. Tidak memakai `tabindex` positif. Status singkat pada region yang sudah ada sejak render awal, bukan region yang baru disisipkan ([WAI status](https://www.w3.org/WAI/WCAG22/Techniques/aria/ARIA22.html), [WCAG focus order](https://www.w3.org/WAI/WCAG22/Understanding/focus-order.html)).

|---|---|---|

## 7. Risiko dan mitigasi

| Risiko | Mitigasi dan gerbang rilis |
|---|---|
| Cookie tutup browser dianggap menghapus data, padahal DB/log/backup/penyedia masih menyimpan | Prune `started_at` per jam, uji cascade dan scheduler; pernyataan privasi menyebut toleransi hingga ~25 jam dan retensi pihak ketiga. Tinjau hukum persetujuan wali sebelum rilis. |
| ID sesi diambil dari properti Livewire/URL atau request silang | Cek session server pada setiap baca dan mutasi, uji dua cookie terpisah dan request Livewire langsung. |
| Biaya AI/penyedia membengkak lewat start acak, kirim, akhir, atau IP proxy palsu | Limit per IP di setiap jalur pemanggil AI; trusted proxies spesifik; pantau 429 dan biaya; uji NAT sekolah dan pesan coba lagi. |
| Rekaman Ucapan atau transkrip keluar ke pihak ketiga tanpa penjelasan | Pemberitahuan sebelum mic; batasi upload, jangan log konten/audio; periksa retensi upload sementara, AI/STT dan privasi wali. |
| HTML/tautan Markdown atau traversal dari file konten | Katalog slug, front matter ketat, CommonMark strip HTML/unsafe links, review manusia dan tes path. |
| MP3 tidak selaras teks atau layanan edge-tts berubah | Generate saat build saja, manifest durasi, pemeriksaan jumlah/isi, dengarkan sampel, commit MP3; simpan opsi ganti penyedia TTS bila generator gagal. |
| Audio aplikasi bertabrakan dengan pembaca layar atau Mode suara membuka mic lagi | Tidak autoplay, push-to-talk satu ujaran, hentikan TTS/MP3 sebelum mendengar, status visual+`role=status`, uji manual empat pembaca layar. Halaman web tidak dapat menghentikan suara screen reader sendiri ([WCAG audio control](https://www.w3.org/WAI/WCAG21/Understanding/audio-control.html)). |
| Penghapusan memutus Ucapan/Ngobrol karena dependensi tersembunyi | Pertahankan kamus service/data, `WeekTopic`, HSK, analisis job; audit `rg` ulang setelah tiap kelompok penghapusan, route list, PHPUnit, build dan E2E. |
